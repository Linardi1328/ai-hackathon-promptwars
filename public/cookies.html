Cookie Policy

The audited Event Twin application does not intentionally use advertising cookies, behavioural analytics, cross-site marketing trackers, or application-level cookies for event profiles.

Effective: 11 September 2026

PrivacyTermsCookiesPayments & refunds

Current implementation

Event simulation state is held in React memory for the current session. The audited source does not intentionally include Google Analytics, Meta Pixel, Hotjar, Mixpanel, PostHog, or similar behavioural tracking libraries.

Hosting infrastructure

The hosting/CDN platform may use technical mechanisms and request logs necessary to serve, cache, diagnose, and secure the website. Those infrastructure functions are distinct from adding marketing tracking to the application.

No performative consent banner

Because the audited app does not intentionally enable non-essential marketing or behavioural tracking, it does not show a cookie-consent banner solely for appearance.

If tracking changes

Before enabling non-essential analytics, advertising pixels, cross-site tracking, or cookie-setting third-party embeds, the project must reassess consent obligations for the relevant audience. Where prior consent is required, those technologies must remain off until a valid choice is obtained and users can later change it.
