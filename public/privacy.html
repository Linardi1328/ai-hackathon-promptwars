Privacy Policy

Event Twin is a synthetic hackathon-event simulation. The audited prototype keeps its event state in browser memory and is not designed to collect or persist real attendee, participant, judge, employee, or customer information.

Effective: 11 September 2026

PrivacyTermsCookiesPayments & refunds

Use synthetic data only

Names, teams, pass codes, scores, announcements, schedules, attendance states, and disruption scenarios in the public prototype should be fictional demonstration data. Do not enter real personal, confidential, security-sensitive, or event credential information into this demo.

Current storage model

The audited application initializes its event data from mock fixtures and keeps changes in React state for the current browser session. It does not include an application database or account system in the audited build.

Hosting and technical logs

The hosting platform may process ordinary technical request information needed to deliver and protect the website, such as IP address, user agent, request time, and security/diagnostic logs. Event Twin does not intentionally use that information to create advertising profiles.

Analytics and third-party embeds

The audited application code does not include behavioural advertising analytics, advertising pixels, or social/video iframe embeds. If non-essential tracking or third-party embeds are added later, privacy and consent requirements must be reviewed before release.

Production use

A real event deployment would require a separate privacy design covering attendee/judge/participant notices, lawful data collection, access control, retention, security, processor contracts, cross-border processing, incident response, and applicable Malaysian law before real personal data is introduced.

This policy describes the public prototype, not a production event-registration platform.
